# OrcaServer

scad-liveのモデルを組み合わせ、家庭内のBambu Labプリンターで順番に印刷するサーバーです。
ブラウザからプレートの構成・個数、材料、AMSスロットを選べます。
印刷を始めると最新のSTLを取得し、OrcaSlicerで自動配置・スライスして送信します。
毎回、造形物を取り外して空のビルドプレートを確認してから「次を印刷」を押します。
プレートと印刷キューは再起動後も残り、次の印刷を自動で始めることはありません。

複数プリンターと単一ノズル・単一材料に対応します。通信はP1SのLAN印刷経路を使います。
他機種の通信・実印刷は未確認です。

## 起動

Dockerを導入したLinux x86_64環境で実行します。OrcaSlicer 2.4.2とprofileを同梱し、GUIは不要です。

```sh
docker run --rm -p 127.0.0.1:3000:3000 -v orca-plates:/data/plates ghcr.io/miyabi-sunny-side/orca-server:latest
```

[プレート一覧](http://127.0.0.1:3000)を開きます。保存データがなければ空の一覧を表示します。
この起動例では、[APIからのSTL保存・検索](docs/plates.md#保存と検索)と保存済みプレートの閲覧を利用できます。
印刷には、以下のプリンター・材料・AMSの登録が必要です。
画面から新規作成する場合は、[コンテナの接続設定](docs/container.md)でscad-liveのURLを指定してください。

プレート・印刷キュー・プリンター設定・材料台帳は`orca-plates`ボリュームへ保存され、コンテナ終了後も残ります。
終了するには実行中のターミナルでCtrl+Cを押します。
この例はホスト内からのアクセスに限定しています。
他の端末へ公開する場合は、家庭内の信頼できるネットワークへ公開範囲を制限してください。

## プリンターを登録する

右上のメニューから「プリンター」→「追加」を開きます。名前、機種・装着ノズル、LAN接続情報と
確認済みの証明書を登録します。[接続設定ガイド](docs/printer.md)に、証明書の取得と各項目をまとめています。
設定はSQLiteに保存されます。待機ジョブだけなら構成を変更できますが、印刷準備中・印刷中・取り外し待ち・要確認の機器は名前だけ変更できます。

## 材料とAMSを確認する

メニューの「フィラメント」で銘柄・色ごとの材料と機種別の温度設定を保存できます。
「プリンター」→「AMSの材料」から、装填された材料を台帳へ対応づけます。
純正品はIDと色などで識別し、サードパーティ製は手動で指定します。
[材料管理ガイド](docs/filaments.md)に、温度設定とスライスの関係、未確認表示、APIをまとめています。

## プレートを作る

scad-liveを接続したサーバーで操作します。

1. 「新規作成」を開き、モデル名で検索してSTLを選びます。複数選択できます。
2. 「構成を確認」でプレート名と個数を指定し、「保存」を押します。
3. 詳細の「印刷キューへ」から、プリンター・使用予定の材料・AMSスロット・印刷条件を選びます。
4. キューで空のビルドプレートを確認し、「次を印刷」を押します。完了後は取り外しを確認して次へ進みます。

待機中は順序・材料・印刷条件を変更できます。予定した材料とAMSの現在の割当が合わなければ保留します。
プレートのモデルと個数は詳細から編集できます。SCADの最新データと材料設定は、印刷準備の開始時に固定します。
[キューの操作と復旧](docs/queue.md)には、保留や再起動後の確認方法をまとめています。
明暗テーマは端末設定に従い、メニューから手動でも変更できます。
