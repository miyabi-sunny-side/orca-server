# OrcaServer

手元のSTL・3MFやscad-liveのモデルをプレートにまとめ、家庭内のBambu Labプリンターで順番に印刷するサーバーです。
ブラウザからプレートの構成・個数と印刷条件を保存できます。AMSは指定材料の使用順に従って自動選択します。
キューへ追加するとOrcaSlicerで自動配置・スライスし、推定所要時間を表示します。
印刷開始時にも最新のモデルと設定を確認してから送信します。
プレートと印刷キューは再起動後も残り、次の印刷を自動で始めることはありません。

複数プリンターと単一ノズルに対応し、サポート接触面には別のAMS材料を指定できます。通信はP1SのLAN印刷経路を使います。
他機種の通信・実印刷は未確認です。

## 起動

Dockerを導入したLinux x86_64環境で実行します。OrcaSlicer 2.4.2とprofileを同梱し、GUIは不要です。

```sh
docker run --rm -p 127.0.0.1:3000:3000 -v orca-plates:/data/plates ghcr.io/miyabi-sunny-side/orca-server:latest
```

[ホーム](http://127.0.0.1:3000)を開きます。プリンターが未登録なら登録への案内を表示します。
ヘッダーの「OrcaServer」でプリンターとキュー、「プレート」で保存済みプレートを開きます。
この起動例では、画面からのファイル取り込み・保存・閲覧を利用できます。
印刷には、以下のプリンター・材料・AMSの登録が必要です。
scad-liveのモデルを選ぶ場合は、[コンテナの接続設定](docs/container.md)でURLを指定してください。

プレート・印刷キュー・プリンター設定・材料台帳は`orca-plates`ボリュームへ保存され、コンテナ終了後も残ります。
終了するには実行中のターミナルでCtrl+Cを押します。
この例はホスト内からのアクセスに限定しています。
他の端末へ公開する場合は、家庭内の信頼できるネットワークへ公開範囲を制限してください。

## プリンターを登録する

右上のメニューから「プリンター」→「追加」を開きます。名前、機種・装着ノズル、LAN接続情報と
確認済みの証明書を登録します。[接続設定ガイド](docs/printer.md)に、証明書の取得と各項目をまとめています。
設定はSQLiteに保存されます。印刷中に変更できる項目も接続設定ガイドで案内しています。

## 材料とAMSを確認する

メニューの「フィラメント」で製品を登録し、その下に色を追加できます。機種別の温度設定は製品の全色で共有します。
「プリンター」→「AMSの材料」から、装填された材料を台帳へ対応づけます。
純正品はIDと色などで識別し、サードパーティ製は手動で指定します。
[材料管理ガイド](docs/filaments.md)に、温度設定とスライスの関係、未確認表示、APIをまとめています。

## プレートを作る

手元のモデルファイルを使う手順です。モデル配信サービスscad-liveを接続している場合は、「新規作成」→「SCADから選ぶ」も使えます。

1. 「プレート」→「ファイル取込」からSTL（複数可）または3MFを選びます。3MFに複数プレートがあれば、名前と形状を確認して選びます。
2. 形状・実寸を確認し、プレート名・個数を指定します。印刷条件は[保存済みの初期値とAMS材料](docs/plates.md#新規作成の初期値)から入り、必要な項目だけ変更して保存します。
3. 詳細の「印刷キューへ」を押すと1件追加します。同じ条件に合う実機が複数あれば、追加先だけを選びます。
4. キューで「空のプレートで印刷を開始」を押します。完了後は空のプレートを戻し、「取り外した・次を印刷」を押します。待機がなければ「取り外した」で終了します。

3MFの選択プレートは部品配置を保った一組として扱い、自動縮小しません。元ファイルは詳細から取得できます。
多色・ペイントを含む3MFも保存できますが、その印刷は未対応です。[取り込み形式と制限](docs/plates.md#ファイルから取り込む)を参照してください。

サポートは初期状態でOFFです。必要なプレートだけ詳細設定でONにし、[接触面のフィラメント](docs/plates.md#サポートを使う)を選べます。

条件が未設定でもプレートを保存できます。キューへの追加には条件の設定と、選んだ実機のAMSで指定材料の装填確認が必要です。
待機順はキュー左端のハンドルで変更します。名前を押すと条件や操作を展開します。
モデル・個数・印刷条件はプレート詳細から編集し、未準備の待機分へ反映します。
プレート一覧の右クリック・長押しから、キュー追加・編集・削除を操作できます。削除しても既存の印刷ジョブは継続します。
SCADの最新データと材料設定は、印刷準備の開始時に固定します。
[キューの操作と復旧](docs/queue.md)には、保留や再起動後の確認方法をまとめています。
[Discordの完了通知](docs/container.md#discordの完了通知)を設定すると、印刷が終わって取り外せることをチャンネルへ知らせます。
明暗テーマは端末設定に従い、メニューから手動でも変更できます。

## MCPから保存・印刷を続ける

Streamable HTTP対応クライアントの接続先に`http://127.0.0.1:3000/mcp`を指定します。
別端末から使う場合は、信頼できるLAN/Tailscale内のサーバーアドレスに置き換えます。
プレートの保存・更新、製品への色追加、共通温度設定、AMSの材料対応と使用順を操作できます。
保存結果にはID・構成・管理画面のパスが含まれます。
キューへ追加した後は、スマホのブラウザやMCPから継続できます。対象が決まっていれば「取り外したので次へ」の指示で進めます。
[MCPガイド](docs/mcp.md)に、toolの引数、モデル10個の保存例、競合時の確認方法をまとめています。
